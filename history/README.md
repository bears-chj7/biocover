## 기록 원칙

- 사용자 진술, 다른 세션 인계, 로컬 파일 확인, 실제 측정 결과를 구분합니다.
- 과거 ‘미설치’ 기록을 삭제해 성공으로 바꾸지 않고 이후 설치 증거를 연결합니다.
- ‘빌드 성공’, ‘설치 완료’, ‘드라이버 로드’, ‘센서 응답’, ‘보정 정확도’를 별도 상태로 기록합니다.
- 시스템 변경에는 대상 파일·백업·검증·미해결 사항을 남깁니다.
- 아카이브 파일은 당시 상태의 사본입니다. 이전 설치 스크립트·복원 안내를 현재 시스템에 그대로 실행하지 않습니다.
- 원시 측정값은 사용자가 명시적으로 요청할 때만 파일로 저장합니다. 이 디렉터리는 장치 구축 이력이며 원시 CSV는 Git에서 제외합니다.
