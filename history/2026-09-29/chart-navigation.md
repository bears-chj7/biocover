# 긴 구간 그래프의 점 숨김과 과거 구간 탐색

사용자는 긴 표시 범위에서 큰 점 때문에 추세가 가려지는 문제를 지적하고,
패널 드래그로 지난 기록을 보는 기능과 좌우 데이터 워터마크를 요청했다.

## 변경

- 실시간·재생 모두 **30분 이상 폭은 점 없이 선만** 표시한다.
  30분 미만은 점 반지름을 2.3px에서 **1.2px**로 줄였다.
  전체 범위는 현재 표시하는 전체 시간 폭으로 기준을 판단한다.
- 패널을 오른쪽으로 드래그하면 과거, 왼쪽으로 드래그하면 이후로 이동한다.
  여섯 그래프는 같은 시간축으로 이동하며 데이터 시작과 최신/재생 시점 밖으로 나가지 않는다.
- 과거 구간은 새로운 값이 도착해도 고정한다. **최신 구간 / 재생 시점** 버튼으로 복귀한다.
  끝까지 이동하거나 범위·세션을 바꾸면 최신/재생 시점을 따라간다.
- 이미 읽은 유효 측정값이 왼쪽/오른쪽에 있을 때만 **← 이전 데이터 / 이후 데이터 →**를 표시한다.
  미재생 미래 행을 미리 표시하지 않는다. 전체 범위에는 화면 밖 데이터가 없어 이동/표시가 없다.
- 그래프 이동은 보기 전용이며 카드·로그·통계·실제 재생 위치·측정 CSV를 변경하지 않는다.
  상단 타임라인 이동은 기존대로 실제 재생 위치를 바꾸고 그 시점의 통계를 다시 계산한다.
- 방향키·Home/End도 지원한다. 모바일의 세로 스크롤은 `touch-action: pan-y`로 유지한다.
- 시간축 이동·그리기를 `web/static/chart.mjs`와 CSS로 공통화했다.
  재생 정적 디렉터리의 상대 심볼릭 링크도 같은 소스를 사용하므로 두 화면의 동작이 일치한다.
- 서버 코드·센서 수집 경로를 바꾸지 않았으며 브라우저 새로고침으로 반영한다.

## 검증

- 그래프 테스트 8개 및 기존 JS 테스트 16개 통과.
  정확히 30분인 경계, 실제 Canvas 점 그리기 생략, 결측·긴 공백의 선 끊김,
  드래그 방향·양 끝 제한·새 측정 중 과거 구간 고정·이진 탐색 범위를 검사했다.
- 실제 Firefox에서 실시간·재생 각각 1,951행 CSV로 검증했다.
  5/10분의 작은 점, 30분/1시간/2시간/전체의 점 생략, 실제 마우스 좌우 드래그,
  여섯 시간축 일치, 양쪽 워터마크, 복귀 버튼, Home/End, 카드·통계 불변을 확인했다.
- 390px 화면에서 가로 넘침 없음, 양쪽 표시 및 세로 스크롤 설정을 확인했다.
- 스크린샷: Git 제외 로컬 경로 `build/chart-pan-replay.png`, `build/chart-pan-live.png`,
  `build/chart-pan-mobile.png`.
- 검증용 서버는 8082와 센서 없는 소스를 사용했다. 실제 8080의 측정 제어 API는 호출하지 않았다.
- 운영 서버에서 `/static/chart.mjs`, `/replay/static/chart.mjs` 모두 HTTP 200.
  작업 전후 PID 16460 및 시작 시각 2026-09-29 13:04:05 KST가 동일했고 8081은 닫혀 있었다.
