# 표시 범위·타임라인 이동·CSV 절대 시각 변경

사용자 요청에 따라 실시간/재생의 표시 범위에 **1시간·2시간·전체**를 추가했다.
재생 진행 막대를 드래그 가능한 타임라인으로 바꿨다. 앞뒤 이동 시 해당 시점까지의
행으로 카드·로그·평균/최솟값/최댓값을 다시 구성한다. 드래그 도중 시계가 움직이지 않으며,
재생 중이었다면 드래그가 끝난 뒤 새 위치부터 이어진다. 완료 상태에서도 이전 시각으로 이동 가능하다.

## 실시간의 전체 이력

기존 API가 최근 720행만 보내므로 선택 항목만 늘려서는 전체가 표시되지 않았다.
읽기 전용 `/api/history?after=0&limit=5000`를 추가해 현재 세션 CSV를 페이지 단위로 읽는다.
CSV 파일을 잠금 안에서 열고 읽기는 잠금 밖에서 수행하며, 읽기 시작 당시 확정된 행까지만 취급한다.
수집 중인 파일의 이름 변경·복구·쓰기·센서 제어는 하지 않는다.

브라우저는 전체 행과 최신 720행을 sequence로 합쳐 중복 없이 보관한다.
서버의 수집 메모리는 계속 최근 720행으로 제한한다. 브라우저를 새로 열어도 세션 시작 부분을
CSV에서 채워 1시간/2시간/전체를 표시한다. 종료 후 새 세션은 별도로 초기화된다.

사용자가 `biocover-web.service`를 재시작했다고 알려줬다.
직접 조회한 결과 active, PID **14825**, 시작 시각 **2026-09-29 12:24:51 KST**였다.
실제 8080의 새 `/api/history`가 HTTP 200으로 응답했다. 재시작 직후 새 측정은 시작하지 않은 상태였다.

## 사용자 요청에 따른 파일 시각 변경

이 변경은 사용자의 **절대 시각을 2시간 일찍 수정하라는 요청**을 적용한 것이다.
실제 장치 시계 오차를 독립적으로 검증해 자동 보정한 결과로 해석하지 않는다.

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 파일명 | `session-20260928T232014.797483Z.csv` | `session-20260928T212014.797483Z.csv` |
| 첫 timestamp, KST | 09-29 08:20:14.817076 | 09-29 06:20:14.817076 |
| 마지막 timestamp, KST | 09-29 11:02:44.974809 | 09-29 09:02:44.974809 |
| 파일 수정 시각, KST | 09-29 11:02:44.973635075 | 09-29 09:02:44.973635075 |
| 실제 생성 시각(birth time), KST | 09-29 08:20:14.791687887 | **변경하지 못함: 기존 값 유지** |

- 1,951행의 `timestamp`, 비어 있지 않은 `uno_received_at`만 정확히 2시간 앞당겼다.
- 센서값, 순번, `elapsed_s`, `uno_time_ms`, `uno_age_s`, 상태·오류는 모두 원본과 동일하다.
- 원본 파일과 manifest는 `data/backups/time-shift-20260929T023941.820286Z/`에 있다.
  원시 CSV는 기존 정책대로 Git에서 제외했다.
- 기존 inode 3694043을 유지해 생성 시각이 작업 당일 시각으로 바뀌는 것도 피했다.
  ext4의 birth time은 일반 파일 API로 수정할 수 없다. 사용 중인 루트 디스크의 inode를 직접
  수정하는 작업은 수행하지 않았다. ctime은 메타데이터 변경으로 작업 시각이 됐다.
  atime은 파일을 다시 읽으면 운영체제가 갱신할 수 있다.
- 재사용 가능한 `scripts/shift_session_time.py`를 추가했다. 기본은 미리보기이며
  `--apply` 때 원본과 변경 이력을 먼저 백업하고 파일을 변경한다. 완료된 일반 CSV만 허용한다.

SHA-256:

```text
원본: bfaca5bdea975aa6e180276c2a4354292314b8ffb76f9c3b66b5ed5bfd9b3a42
변경: dfba9f7b99979ca4d298d18f1cdb9ad79c8dcc837609918b6afcc7fbd2c70fd1
```

## 검증

- Python 테스트 18개, JS 재생 13개 + 실시간 이력 3개 통과.
- 실제 CSV 1,951행을 원본과 전수 비교: 절대 시각 두 열만 -2시간, 나머지 열 모두 동일.
- Firefox에서 실제 마우스 드래그, 완료 후 뒤로 이동·재개, 해당 시점의 평균·로그를 검증했다.
- 센서 없는 별도 8082 테스트 서버에서 최근 720행 밖의 전체 CSV를 가져오고,
  그래프가 06:20:14~09:02:44 전체 구간을 표시함을 브라우저와 스크린샷으로 확인했다.
- 테스트용 서버·브라우저는 종료했다. 운영 재생 서버의 재시작은 필요하지 않았다.
- `build/replay-full-range.png`, `build/live-full-range.png`는 로컬 확인용이며 Git에서 제외한다.
