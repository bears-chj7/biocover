## 다음 순서

1. P7 pinconf 조회는 완료됐습니다. 원문은 [증거 파일](artifacts/pin7-pinconf-user.txt)에 보관했습니다. 다음은 당시 사용한 조회 명령입니다.

```bash
sudo grep -i -A 14 'soc_gpio59_pac6' /sys/kernel/debug/pinctrl/2430000.pinmux/pinconf-groups
```

2. P7 설정 반영을 확인했으므로 DS18B20 전원·공통 GND·실제 4.7kΩ 풀업과 DATA 신호를 확인하며 드라이버 타이밍 가능성도 남겨 둡니다. 설정 변경은 기존 통합 SPI/P15/P7 내용을 보존합니다.
3. DHT22의 누락 없는 읽기 방식을 검증합니다. 현재 C 후보는 성공한 구현이 아닙니다.
4. 센서 검증 후 실험용 5초 CSV 수집, 보정, 유량·희석·실험 대조 설계를 구현합니다.

## 하지 않은 작업

이력 정리 과정에서 모듈 재설치·부팅 설정 변경·재부팅·가스 공급·파일시스템 복구는 하지 않았습니다. 센서가 정상 동작한다고 가정한 가짜 온도·농도 데이터도 생성하지 않았습니다.
