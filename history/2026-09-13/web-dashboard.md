# 로컬 센서 웹 대시보드 구현

사용자 요청: 로그인 없는 흰색 대시보드, 시작 후 최신 센서값을 5초마다 갱신,
측정 로그와 이동하는 시계열 그래프, 집계, 일시정지/정지, 정상·비정상 종료 CSV 보존.
이번 요청에 따라 시작 버튼이 측정 및 CSV 기록의 명시적 시작이다.
부팅/웹 페이지 열기 자체는 측정 CSV를 생성하지 않는다.

## 구현

- Flask 3.1.2 서버, 로컬 CSS/JavaScript/Canvas 화면. 127.0.0.1:8080.
- UNO 9600bps 입력을 별도 스레드에서 수신하고 6초 이상 오래된 값은 결측 처리.
- 5초마다 UNO 최신값과 ADC CH0/CH1/CH4를 결합. 6개 수치 및 미연결 장치 표시.
- 시작/일시정지/재개/정지, 세션 유효값 평균/최솟값/최댓값.
- 그래프 최근 5/10/30분, 로그 최근 120행, 서버 최근 720행 메모리 보관.
- 타임스탬프 CSV를 매 행 flush/fsync. 정상 종료 시 파일 마무리,
  강제 종료 뒤 재시작 시 부분 파일의 불완전 마지막 행을 제거하고 recovered로 보존.
- 브라우저 연결 45초 단절 시 측정 정지·저장. 재시작 후 자동 측정 재개 없음.
- 기존 자동 CSV 수집 중지 및 대시보드 설치 스크립트 작성.
  서비스가 부팅해도 사용자가 시작하기 전에는 센서를 열지 않는다.

## 검증과 현재 적용 상태

6개 unittest 통과: 세션 제어/중복 요청, 주기/일시정지/NaN 집계,
브라우저 연결 단절, USB 신선도, 다운로드 및 제어 출처 검사,
실제 별도 프로세스 SIGKILL 후 CSV 복구.
Python 문법, JavaScript 문법, systemd 서비스 문법 검증 통과.
합성 입력만 사용하는 별도 테스트 HTTP 서버를 실행했고 테스트 후 종료했다.

Chromium 화면 캡처는 환경 문제로 완료하지 못했다:
Snap 권한 오류, 직접 실행의 GLIBC 버전 차이, 번들 로더 실행의 ICU 오류.
따라서 브라우저 시각 검증 완료로 기록하지 않는다.

`sudo -n python3 scripts/install_dashboard.py`는 비밀번호 필요로 실패했다.
실제 웹 서비스 설치와 웹 화면에서의 센서 수신은 사용자 sudo 실행 후 검증해야 한다.
기존 자동 CSV 수집을 중지했다고 단정하지 않는다.

## 사용자 후속 지시: 웹서비스도 수동 실행

웹서비스 자체도 원할 때만 시작하도록 지시했다. 설치기를 변경해 서비스 등록 후
disable --now를 수행하고 자동 시작하지 않도록 했다. Restart=no로 오류 후 자동
재시작도 하지 않는다. 시작/종료는 systemctl start/stop으로 분리했다.
설치기 Python 문법 및 diff 검증 통과.
기존 설치 상태에 대해 에이전트가 disable --now를 시도했으나 sudo 비밀번호 필요로
실패했다. 실제 서비스 중지/자동 시작 해제 완료로 기록하지 않는다.

## 외부 IP 접속 요청

실제 조회: 웹서비스 active, 부팅 자동 실행 disabled. 실행 주소 127.0.0.1:8080,
Wi-Fi wlP1p1s0 주소 192.168.123.101/24. 앱도 localhost Host만 허용해 IP 접근 불가였다.
기본 바인딩을 0.0.0.0으로 바꾸고 IPv4/IPv6 literal Host를 허용했다.
다른 출처의 제어 요청 거부는 유지하며 IPv4 리스너가 기본이다.
IP GET/같은 출처 POST 성공, 다른 출처 POST 및 도메인 Host 거부 테스트 추가.
기존 실행 프로세스 재시작 및 방화벽 실제 조회는 사용자 sudo 실행 대기.
check_web_network.py는 재시작·자기 IP 검사·UFW/INPUT 조회만 수행하고
방화벽 규칙을 변경하지 않는다. 공유기나 다른 기기의 도달성은 아직 검증하지 않았다.
