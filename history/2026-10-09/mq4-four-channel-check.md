# MQ-4 네 개 연결 후 ADC 점검

사용자가 MQ-4 네 개 연결을 보고하여 기존 배정(#1 CH0, #2 CH1, #3 CH2, #4 CH3)을 기준으로 확인했다.
물리 배선·센서 위치를 직접 검사한 것은 아니다.

## 확인 방법

- 2026-10-09 22:42:49~22:42:59 KST, 호스트 `/dev/spidev0.0` 조회.
- SPI mode 0 확인 후 100kHz·500kHz에서 각각 채널당 10회, 0.5초 간격으로 읽었다.
- 기존 수집 코드와 같은 장치 잠금을 사용했다. SPI 설정·부팅 설정을 변경하지 않았다.
- 웹서비스 PID 4389, API 상태 `idle`, 측정 횟수 0을 먼저 확인했다.
  서비스 재시작·측정 시작·CSV 저장은 수행하지 않았다.

## 결과

전압은 실측 VREF가 아닌 공칭 3.3V에 따른 ADC 입력 전압 환산이다.

| 센서 | 채널 | 100kHz 평균 raw / 전압 | 500kHz 평균 raw / 전압 | 전체 raw 범위 |
|---|---|---|---|---|
| MQ-4 #1 | CH0 | 234.9 / 0.758V | 235.1 / 0.758V | 233~237 |
| MQ-4 #2 | CH1 | 374.2 / 1.207V | 372.6 / 1.202V | 370~376 |
| MQ-4 #3 | CH2 | 714.0 / 2.303V | 713.6 / 2.302V | 712~719 |
| MQ-4 #4 | CH3 | 526.8 / 1.699V | 525.4 / 1.695V | 523~528 |
| 토양수분 | CH4 | 829.9 / 2.677V | 829.4 / 2.675V | 828~832 |

네 MQ-4 채널 모두 0 또는 최대값 1023에 고정되지 않았고 두 속도에서 비슷한 값이 나왔다.
확인한 범위는 ADC 통신과 입력값 수신이다. 이 결과만으로 센서별 메탄 응답·ppm 정확도·예열 완료를 검증할 수는 없다.
이전 미연결 CH2/CH3 기록은 당시 상태로 유지한다.

## 소프트웨어 반영 상태

`scripts/show_all_sensors.py`의 `read_adc()` 및 `web/sensors.py`는 CH0·CH1·CH4만 수집한다.
현재 웹·CSV에는 #3/#4가 포함되지 않는다. 이번 요청은 연결 점검이므로 수집 형식·화면은 변경하지 않았다.
향후 네 센서 통합 수집 시 CSV 필드, 실시간·재생 화면, 이전 CSV 호환성을 함께 반영해야 한다.
