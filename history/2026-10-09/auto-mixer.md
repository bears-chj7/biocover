# 유출 #2/#3/#4 변화 감지에 따른 자동 교반

사용자는 이해한 내용을 먼저 설명한 뒤, 유출 센서 간 평소보다 큰 차이 또는 최근 평균 대비 급상승을
감지해 간격을 두고 모터를 구동하는 코드를 요청했다.
추가 지정: 0° → 180° → 0°, 각 위치에서 1초 대기.

최근 60초 기준, 격차 증가 40 raw 이상/3표준편차, 평균 상승 30 raw·15%·3표준편차 중 큰 기준,
같은 조건 2회 연속 확인, 180초 재구동 대기를 초기 설정으로 구현했다.
비교식과 예외는 [자동 교반 안내](../../docs/auto-mixer.md)에 정리했다.

- 자동 구동 기본 꺼짐. 측정 중에 사용자가 켜야 동작한다.
- 5초 센서 기록을 막지 않는 별도 제어 흐름과 비동기 명령 등록 사용.
- ACK 후 1초 대기. 주기 완료 후 180초 대기, 기준 재수집.
- 측정 정지/일시정지/수동 명령/결측/범위 끝값/통신 실패/UNO 리셋 시 해제.
- 재생·과거 0 채움은 제어 입력으로 사용하지 않음.
- 브라우저 설정·판단값·최근 이벤트 표시. 서비스 로그에 AUTO_MIXER JSON 기록.

검증: Python 45개, JavaScript 25개 통과.
정상 센서 오프셋, 현재값 제외, 연속 확인 중 기준 오염 방지, 단발 노이즈,
절대값/상승률/표준편차 기준, 잘못된 입력, 각도 순서·ACK·1초·대기·중단·재시작 세대 검사 포함.
Firefox와 센서 없는 8082 서버에서 기본값, 설정 저장, 측정 전 활성화 거부,
숫자 명령 미전송, 390px 모바일 가로 넘침 없음을 확인했다. 검증 서버 종료 완료.
스크린샷은 Git 제외 build/mixer-desktop.png 및 build/mixer-mobile.png.

실제 모터로 자동 구동 시험은 하지 않았다. 운영 서비스 PID 10621과 진행 중인 측정을 유지했다.
