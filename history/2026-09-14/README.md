# 2026-09-14 작업 이력

## 사용자 조작 없는 측정 정지 원인

사용자가 조작하지 않았는데 측정이 멈췄다고 보고했다.
에이전트 직접 조회 결과 웹서비스는 active로 약 2시간 실행 중이었고,
API 상태는 stopped, reason은 `브라우저 연결 시간 초과`, error는 빈 문자열이었다.
사용자의 실제 화면 잠금/앱 전환 여부는 확인하지 않았으므로 단정하지 않는다.

원인은 서버에 넣었던 브라우저 heartbeat 45초 만료 조건이다.
센서 통신 실패나 서비스 크래시로 인한 중단은 아니었다.
세션 CSV `session-20260913T132148.547989Z.csv`를 직접 열어 117행 보존을 확인했다.
마지막 행 UTC 2026-09-13 13:31:28.702829 (KST 22:31:28.702829).

## 수정

- 브라우저 연결 여부에 따른 자동 측정 정지를 제거했다.
- 모바일 화면 잠금, 탭 전환, 브라우저 종료 후에도 서버 측정/CSV 기록이 계속된다.
- 일시정지도 연결 여부와 무관하게 유지한다.
- 종료는 사용자 정지, 서비스 종료 또는 측정/저장 오류로 처리한다.
- 정상 종료 CSV 저장, 매 행 fsync 및 비정상 종료 후 복구는 유지한다.
- 과거 페이지와의 호환을 위해 heartbeat API는 남기되 세션 상태에 영향을 주지 않는다.
- 화면 문구·README·사용 문서를 갱신했다.
