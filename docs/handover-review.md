# 전체 인계 개요 반영 기록 — 2026-09-13

사용자 제공 ‘바이오커버 메탄 산화 측정 실험 — 전체 인계 문서’를 README의 프로젝트 개요로 편집·반영했습니다. 문장 그대로의 원문 사본이 아니라, 현장 확인과 검토를 반영한 관리 문서입니다.

## 현재 사실로 갱신한 내용

- 부팅 불가 → 부팅·SPI 활성화 확인, DHT22 설정 설치 후 재부팅 대기.
- MQ-4 #3·#4와 CM1106은 미연결. DS18B20은 연결.
- 센서 ‘7종’ → 센서 5종, 계획 8개, 별도 ADC 1개.
- DS18B20은 단순 modprobe 단계가 아니라 현재 커널의 1-Wire 지원부터 필요.
- 함수·라이브러리·GPU·CSV 수집은 검증/구현 완료가 아니라 향후 계획.

## 가설·설계 후보로 구분한 내용

논흙의 균 풍부도, 일반 흙의 낮은 활성, 시판 흙의 부적합성, 며칠 내 차이 발생, 산화 깊이, pH·수분·배양기간은 이 실험에서 검증되지 않았습니다. 혼합비·수분의 단위 기준도 미정입니다. 원안의 범위와 의도는 README에 유지하되 확정 결과로 표시하지 않았습니다.

## 측정 해석에서 보완한 내용

ADC 전압을 CH4 농도로 간주하지 않음. 상부 외기 유입에 의한 희석과 유량 차이, CO2의 다른 발생원, 체류시간·비정상상태를 구분해야 함. 농도 변화율은 곧바로 플럭스가 아님. 음수 제거율은 보존하고 0 이하 유입은 무효 처리. 원안 파서는 체크섬·CRC·상태 검증이 부족하므로 실험 코드로 채택하기 전 보완 필요.

## 안전 문구에서 보완한 내용

자가 밀폐 페트병 발생조, 40% CH4 공급, 물트랩의 역화 방지 보장, 점화원 배제만으로 낮은 폭발 위험, 악취 85% 이상 제거 등은 확정 운용 절차·성능 보장으로 채택하지 않았습니다. 가스 공급 방식은 미확정이며 전문 검토 후 결정합니다. 관련 제조사·EPA·NIOSH 출처는 README의 해당 문단에 연결했습니다.

## 저장소 반영 상태

README와 기존 배선·진단·오버레이 자료를 초기 Git 기록으로 관리합니다. 이 문서 반영 작업 중 재부팅, 가스 공급, 라이브러리 설치 또는 실험용 수집 코드 구현은 수행하지 않았습니다.
