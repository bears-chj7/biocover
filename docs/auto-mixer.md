# 유출 센서 기반 자동 교반

실시간 측정 중 MQ-4 #2·#3·#4의 보정 전 ADC raw를 비교한다.
기본은 꺼짐이며 웹 실시간 탭에서 **자동 교반 켜기**를 눌러야 활성화된다.
센서값은 메탄 ppm으로 보정한 농도가 아니다. 아래 수치는 조정 가능한 초기 설정이다.

## 판단과 동작

매 5초마다 성공적으로 CSV에 기록된 새 측정값으로 다음을 계산한다.

- `평균 M = (mq2 + mq3 + mq4) / 3`
- `격차 D = max(mq2, mq3, mq4) - min(mq2, mq3, mq4)`
- 직전 60초의 M, D 각각에 대해 평균과 표준편차를 계산한다. 현재 행은 비교 기준에 넣지 않는다.
- 격차 조건: `D > 기준 격차 평균 + max(40 raw, 격차 표준편차 × 3)`
- 상승 조건: `M > 기준 평균 + max(30 raw, 기준 평균 × 15%, 평균 표준편차 × 3)`

두 조건 중 같은 조건이 **연속 2회** 충족되면 교반한다. 한 번 튄 값이나 센서 간 평소 오프셋만으로는 구동하지 않는다.
연속 확인 중에는 기준을 잠깐 고정해 첫 이상값이 다음 판단을 가리지 않게 한다.
이상 후보가 계속 교대로 나타나면 `(연속 횟수+1) × 측정 간격`을 초과한 후 기준을 다시 수집한다.
기준 시간과 충분한 유효 표본 수를 확보하기 전에는 판단하지 않는다.

사용자 지정 동작은 **0° → 180° → 0°**다. 각 명령의 `#ANGLE` 확인 응답 후 **1초 이상** 기다린다.
별도 실행 흐름으로 처리하므로 5초 센서 수집을 기다리게 하지 않는다.
한 주기를 끝내면 **180초 동안 재구동하지 않고**, 이후 평소 기준을 새로 수집한다.
따라서 지속적인 높은 값만으로 짧은 간격의 교반을 반복하지 않는다.

## 사용과 중단

1. 진행 중인 측정은 웹에서 정지·저장한다.
2. 새 코드를 반영한다: `sudo systemctl restart biocover-web.service`.
3. 웹페이지를 새로고침하고 측정을 시작한다. UNO 연결·상태 확인이 완료되어야 한다.
4. **감지·동작 설정**에서 필요하면 기준/각도/대기 시간을 변경하고 저장한다.
5. **자동 교반 켜기**를 누른다. 상태·최근 판단값·최근 동작을 화면에서 확인한다.

설정은 현재 프로세스 메모리에 유지되며 서비스 재시작 시 기본값으로 돌아간다.
자동 활성화 상태는 새 측정·일시정지·정지·재시작 시 유지되지 않는다. 재개 후에도 직접 다시 켜야 한다.
자동 교반 끄기 또는 수동 각도 전송은 다음 자동 명령을 취소한다.
이미 아두이노로 전달된 각도 명령의 물리 동작을 되돌리는 기능은 아니다.

다음 경우 자동 교반을 끄고 오류를 표시한다.

- #2/#3/#4 결측·ADC 오류·과거 0 채움·0 또는 1023의 범위 끝값.
- 12.5초(5초 간격의 2.5배) 동안 새 측정값 없음.
- UNO 연결 해제·재시작·명령 오류·3초 내 각도 확인 응답 없음.

원인을 확인하고 상태를 조회한 후 직접 다시 켠다. 자동 명령을 재전송하지 않는다.
재생 CSV는 제어 입력으로 사용하지 않는다. 과거에 추가한 #3/#4의 0도 자동 제어에 사용하지 않는다.

## 코드와 기록

- `web/mixer.py`: 설정 검증, 직전 구간 비교, 교반 순서·확인 응답·대기 상태.
- `web/motor.py`: 같은 USB 연결의 비동기 명령 등록·취소 및 UNO 재시작 세대 검사.
- `GET /api/mixer`: 설정·상태·최근 판단·이벤트.
- `POST /api/mixer/settings`: 설정 변경. 활성 상태에서는 변경 거부.
- `POST /api/mixer/enable`, `/disable`: 자동 제어 활성화/중단. 켜기는 측정 중에만 허용.
- `web/static/mixer.js`, `mixer.css`: 웹 설정과 상태 표시.
- `tests/test_mixer.py`: 정상 오프셋·상승·격차·오감지·결측·동작 순서·대기·중단 검증.

각도 자체는 기존 5초 CSV의 `motor_angle`에 기록한다. 그 사이에 일어난 중간 각도는 CSV에서 보이지 않을 수 있다.
감지 이유와 판단값, 전송 각도, 확인·완료·중단 이벤트는 서비스 로그에 `AUTO_MIXER` JSON으로 기록한다.
최근 60개 이벤트는 서버 메모리, 최근 8개는 화면에 표시한다.

```bash
journalctl -u biocover-web.service -f
```
