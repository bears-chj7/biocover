# 유출 센서 기반 자동 교반

MQ-4 #2·#3·#4가 각각 자기 기준에서 얼마나 변했는지 비교한다. 보정 전 ADC raw의 상대 변화이며 메탄 ppm이나 정화율이 아니다. 새 측정의 기본 상태는 꺼짐이다.

## 판단 기준

5초마다 CSV 저장에 성공한 새 값으로 판단한다.

- 최근 15초의 센서별 중앙값을 사용해 한 번만 튀는 값을 줄인다.
- 그 직전 180초에서 센서별 기준 평균을 계산한다. 최근 15초와 기준 구간은 겹치지 않는다.
- 센서별 변화율 = `(최근 중앙값 − 자기 기준 평균) / 자기 기준 평균 × 100`.
- 편차 조건: 센서별 변화율의 최댓값−최솟값이 **3%p 또는 해당 센서 쌍의 평소 변화율 차이 표준편차 2배 중 큰 값**을 넘는다. 두 센서 중 하나는 자기 기준에서 **5 raw 초과** 변해야 한다.
- 공통 상승 조건: 세 변화율의 평균이 **2% 또는 평소 평균 변화율의 표준편차 2배 중 큰 값**을 넘고, 세 센서 raw 변화량의 평균도 **5 raw 초과**여야 한다.
- 같은 조건이 **3회 연속** 충족되면 교반한다. 후보 확인 중에는 기준을 잠깐 고정한다.

센서의 원래 raw 값이 서로 다르다는 이유만으로는 교반하지 않는다. 낮았던 센서가 올라 절대값 간격이 줄어들더라도, 센서별 변화율이 벌어지면 감지할 수 있다. 사용할 최근 기록이 없는 경우 새 기준 수집에는 기본 195초가 필요하다.

동작은 **0° → 180° → 0°**, 각 `#ANGLE` 응답 후 **1초 대기**다. 완료 후 **180초 재구동 대기**와 새 기준 수집을 거친다. 명령 확인·대기는 별도 스레드에서 처리해 센서 저장을 막지 않는다.

## 설정과 중단

웹 실시간 탭에서 자동 교반을 켠다. 설정 변경 시 교반만 끄고 설정을 저장한 다음 다시 켠다. 이 과정에서 CSV 수집은 계속된다. 다시 켤 때 같은 측정 세션의 최근 값을 새 설정으로 불러오므로, 충분한 기록이 있으면 다음 측정부터 판단한다. 이전 감지 횟수나 각도 명령은 재실행하지 않는다.

일시정지·정지·수동 각도 명령은 자동 교반을 끈다. 결측, ADC 오류, 0 채움, 0/1023 입력, 12.5초 이상 새 데이터 없음, USB 재연결·UNO 재시작, 명령 오류·3초 응답 시간 초과도 자동 교반을 중단한다. 재생 CSV는 제어에 사용하지 않는다.

## 서비스 재시작과 이어 쓰기

`data/web/session-state.json`에 현재 CSV 파일명, 실행/일시정지 상태, 시작 시각, 행 수, 측정 간격과 교반 설정을 원자적으로 저장한다. 센서 측정값 자체는 기존 CSV에 저장한다.

- 서비스 재시작 시 같은 `.partial.csv`에 이어 쓴다. 시작 시각·순번·누적 통계를 복원한다.
- 재시작 시간은 경과 시간에 포함한다. 공백을 가짜 측정값으로 채우지 않는다.
- 일시정지 상태였다면 일시정지 상태로 복원한다.
- 켜져 있던 자동 교반은 USB 상태 확인 후 같은 CSV의 최근 유출 센서 값으로 기준을 복원한다. 충분한 최근 데이터가 있으면 첫 새 측정부터 판단하며, 재시작만으로 195초를 다시 기다리지 않는다. 복원한 과거 행은 명령을 발생시키지 않고, 연속 감지 횟수는 새 측정으로 확인한다.
- 최근 기준 구간에서 벗어난 오래된 값, 오류 값, 기록 내부의 긴 공백 이전 값은 사용하지 않는다. 짧은 서비스 중단은 이어 판단하지만, 남은 유효 기록이 부족하면 필요한 기록을 더 모은다.
- 교반 후 재구동 대기의 종료 시각도 저장·복원한다. 교반 전 데이터로 대기를 건너뛰거나 기준을 되돌리지 않는다. 명령 전송/위치 대기 중 중단됐다면 자동 구동은 꺼진 상태로 복원한다.
- 웹의 **정지**는 CSV를 완료하고 자동 이어 쓰기를 해제한다.
- 재개 정보가 없는 과거의 미완료 CSV는 기존처럼 `-recovered.csv`로 보존한다. 재개 정보나 CSV 검증이 실패하면 오류를 표시하고 원본을 보존한다.

```bash
sudo systemctl restart biocover-web.service
```

이어 쓰기를 지원하지 않는 구버전 서버를 처음 교체할 때만 다음 인계 스크립트를 먼저 실행한다. 진행 중 CSV의 별도 백업을 만든다.

```bash
python3 scripts/prepare_session_resume.py
sudo systemctl restart biocover-web.service
```

기존 프로세스는 파일 수정만으로 새 판정 코드를 실행하지 않는다. API 설정 변경은 즉시 적용되지만 판정 방식 변경에는 위 재시작이 필요하다. 웹페이지도 새로고침한다.

## 기록

5초 CSV에는 `motor_angle`과 응답 시각이 기록된다. 중간 각도는 측정 사이에 지나갈 수 있으므로, 감지 이유·센서별 변화율·전송·확인·완료 이벤트는 서비스 로그의 `AUTO_MIXER` JSON으로 확인한다.

```bash
journalctl -u biocover-web.service -f
```

`GET /api/mixer`의 `algorithm=relative_v1`은 새 판정 코드가 실행 중임을 뜻한다. 최근 이벤트는 같은 API와 웹 화면에서 확인할 수 있다.
